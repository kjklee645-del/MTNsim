# MTNsim 논문 작성계획

작성일: 2026-03-10
대상 프로젝트: MTNsim
문서 목적: 현재까지 구현된 MTNsim의 구조, 실험 결과, 한계를 바탕으로 1차 논문 집필 전략을 고정한다.

## 1. 논문 방향

현재 MTNsim은 실측 기반 보정이 완료된 상용 수준 예측모델 논문보다는, 다음 성격의 논문에 적합하다.

- 미시 교통 시뮬레이션 기반 교통소음 해석 프레임워크 제안
- 개별 차량 궤적 기반 소음 시계열 계산 방법 제안
- 속도 제어, 차로 변경, 차폐물, 재질 속성에 따른 시나리오 비교 실험

따라서 1차 논문은 다음 성격으로 설정한다.

- 논문 유형: 방법론 제안 + 프로토타입 구현 + 시나리오 실험
- 권장 수준: 국내 학회 논문 또는 방법론 중심 투고
- 후속 확장: 실측 calibration/validation을 추가한 저널 논문

## 2. 핵심 주장

본 논문에서 주장해야 할 핵심은 아래와 같다.

1. 평균 교통량 중심 소음평가 대신, 개별 차량 궤적 기반 미시 시뮬레이션으로 시간축 소음 변화를 표현할 수 있다.
2. 교통 제어 이벤트와 장면 객체(방음벽, 건물)의 기하학적 특성을 시나리오 수준에서 재현 가능하게 다룰 수 있다.
3. 장면 객체별 전파 속성 및 재질 속성을 반영하는 모듈형 구조를 통해 향후 정교한 물리모델과 AI 기반 제어로 확장 가능한 기반을 마련했다.

## 3. 현재 논문에 사용할 수 있는 근거

### 3.1 구현 근거

- manifest/scenario 기반 재현 가능한 실행 구조
- SUMO 연동 기반 개별 차량 궤적 생성
- receiver timeseries 및 grid snapshot 출력
- 시나리오 비교 서비스
- 차폐, 반사, 회절의 모듈 분리 구조
- barrier/building 기반 scene object 처리
- material-aware propagation 1차 반영

### 3.2 실험 근거

현재 정리된 대표 비교 결과는 다음과 같다.

- baseline vs speed_drop_80: 평균 receiver mean level 약 -1.60 dB
- baseline vs lane_change_enforce: 평균 약 -0.10 dB
- baseline vs barrier_shielding: 평균 약 -4.74 dB
- baseline vs building_shielding: 평균 약 -5.56 dB
- building_shielding_default vs building_shielding: 평균 약 -0.31 dB

마지막 비교에서는 가까운 수음점은 감소하고 일부 먼 수음점은 증가하여, 1차 반사 효과가 실제 계산 결과에 반영됨을 보여준다.

## 4. 현재 논문의 한계와 서술 원칙

논문에서는 아래 한계를 반드시 명시해야 한다.

- reflection/diffraction은 아직 heuristic 기반 1차 모델이다.
- building은 footprint edge 기반 근사다.
- shielding path는 현재 CPU 경로 중심이다.
- 실측 소음계 데이터 기반 calibration 및 validation이 아직 없다.
- 결과는 engineering check 수준이며 field validation 결과가 아니다.

서술 원칙은 다음과 같다.

- 검증되지 않은 부분을 과장하지 않는다.
- 대신 재현성, 구조적 확장성, 시나리오 비교 능력을 강점으로 밀고 간다.
- 상용 툴 대체 완성본이 아니라, 차세대 교통소음 디지털 트윈 엔진의 핵심 커널이라는 점을 강조한다.

## 5. 권장 논문 구성 전략

### 전략 A. 1차 논문

주제:
개별 차량 궤적과 장면 객체 기반 전파 보정을 결합한 미시 교통소음 시뮬레이션 프레임워크

구성:
- 문제정의
- 기존 방법의 한계
- MTNsim 구조와 방법론
- 대표 시나리오 실험
- 구현 한계 및 향후 과제

### 전략 B. 2차 논문

주제:
실측 소음 데이터 기반 MTNsim calibration 및 validation

구성:
- 센서 설치 및 데이터 수집
- calibration 파이프라인
- 예측 정확도 평가
- 기존 모델 또는 기준식과의 비교

## 6. 지금 바로 필요한 추가 작업

1. 논문용 그림 생성
- 시스템 아키텍처도
- 시나리오 공간 배치도
- receiver 시계열 그래프
- 대표 grid heatmap

2. 논문용 표 생성
- 시나리오 입력 비교표
- 시나리오 결과 요약표

3. 실험 정리
- 각 시나리오의 목적, 변경 변수, 기대 효과를 한 줄씩 정리
- receiver별 통계량을 표준 포맷으로 다시 정리

4. 문장화
- 서론 문제정의 문단
- 연구기여 3개 항목
- 실험 결과 해석 문단
- 한계 및 향후 연구 문단

## 7. 집필 우선순위

1. 제목 후보 확정
2. 논문 목차 초안 확정
3. 초록 초안 작성
4. 그림/표 목록 확정
5. 결과 그림/표 생성
6. 본문 1차 작성
7. 한계 및 기여 정리
8. 투고 형식 맞춤 수정

## 8. 권장 일정

### 1단계
- 논문 목차와 초록 확정
- 실험 그림/표 목록 확정

### 2단계
- 결과 시각화 산출
- 본문 핵심 섹션 초안 작성

### 3단계
- 문장 정제
- 투고 양식 반영
- 공동 검토 및 수정

## 9. 현재 결론

현재 MTNsim은 논문 작성이 가능한 단계다. 다만 논문의 중심은 정확도 검증 완료 모델이 아니라, 미시 교통류와 장면 객체 기반 전파를 결합한 재현 가능한 시뮬레이션 프레임워크 제안이어야 한다. 논문은 지금 바로 시작할 수 있고, 이후 calibration/validation 결과를 추가해 후속 논문으로 확장하는 전략이 가장 현실적이다.
